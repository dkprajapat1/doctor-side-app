# Hospital Management System

A full-stack hospital management application with a separate **Frontend** and **Backend** architecture.

## 📁 Project Structure

```text
hospital/
├── backend/     # Node.js + Express + MongoDB API
├── frontend/    # Next.js frontend
├── .gitignore
└── README.md
```

## 🚀 Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **API:** REST API

## ⚙️ Setup

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create the required `.env` files according to your local configuration.

## ✨ Features

* Doctor management
* Patient management
* Authentication & authorization
* Emergency handling
* Doctor slot management
* RESTful backend APIs
